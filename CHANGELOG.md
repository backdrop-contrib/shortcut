# Changelog

## 1.x-2.0.0 - 2025-12-12

- First public release for the 2.x branch, aligning with Backdrop 1.x best practices.
- Introduced a hover-driven active-set badge that doubles as a color-coded dropdown for instant set switching.
- Added per-set toolbar colors to dropdown options and honored destinations when activating sets.
- Refined toolbar presentation, including simplified toggle controls and reduced manage-icon sizing for better alignment.
- Updated documentation to cover the new workflow, terminology updates, and accessibility improvements.
